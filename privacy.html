プライバシーポリシー

最終更新日: 2026年10月9日

1. はじめに

Aroid PLANTS（以下「当方」）は、観葉植物の生産・販売と、その情報発信を行う個人事業者です。当方は、自らが運営するSNSアカウントへ自らが制作した動画を投稿するための仕組みを運用しています。本ポリシーは、その運用において個人情報をどのように取り扱うかを定めるものです。

2. 取得する情報

当方が取得・保有するのは、当方自身のSNSアカウントに投稿するために必要な認証情報のみです。具体的には次のものです。

  • 当方が運営するSNSアカウントのアクセストークンおよび更新トークン
  • 当方のアカウント名およびアカウントID

当方は、他の利用者の投稿、プロフィール、氏名、連絡先、位置情報その他の個人情報を、取得も保存もしません。

3. 利用目的

取得した情報は、当方が制作した植物の紹介動画と説明文を、当方自身のSNSアカウントへ投稿する目的にのみ利用します。それ以外の目的には利用しません。

当方は、取得した情報を広告配信、プロファイリング、機械学習の学習データ、その他の分析に利用しません。

4. 保管と安全管理

認証情報は、当方の管理するコンピュータの内部にのみ保存し、クラウドストレージや共有フォルダには保存しません。外部のサーバーへ送信することもありません。

認証情報を取り扱うのは事業主本人のみです。

5. 第三者提供

当方は、取得した情報を第三者へ提供、販売、貸与、共有することはありません。法令に基づき開示を求められた場合を除きます。

また、各SNSのAPIを通じて得た情報を、当該SNSの外部で表示・再配布することはありません。

6. 利用するサービス

当方は、投稿のために次のサービスのAPIを利用します。各サービスにおける情報の取り扱いは、それぞれの事業者のプライバシーポリシーに従います。

  • TikTok（TikTok Content Posting API）
  • Instagram および Facebook（Meta Graph API）
  • YouTube（YouTube Data API）

YouTube API サービスについて：当方の投稿ツールは YouTube API サービスを利用して、当方自身のYouTubeチャンネルへ動画をアップロードします。YouTubeの利用には YouTube 利用規約 が適用され、Googleによる情報の取り扱いには Google プライバシーポリシー が適用されます。当方へのアクセス許可は、Google アカウントのセキュリティ設定 からいつでも取り消せます。

Our publishing tool uses YouTube API Services to upload videos to our own YouTube channel. By using YouTube you agree to the YouTube Terms of Service; Google's handling of data is governed by the Google Privacy Policy. Access can be revoked at any time via the Google security settings page.

7. 保存期間と削除

認証情報は、当該SNSでの発信を継続する間のみ保有します。発信を終了した場合、または各SNSの連携を解除した場合は、速やかに削除します。

各SNSの設定画面から、利用者ご自身の判断でいつでも当方の連携を解除できます。

8. 本ポリシーの変更

本ポリシーの内容を変更する場合は、本ページに変更後の内容を掲載し、最終更新日を改めます。

9. お問い合わせ

本ポリシーに関するお問い合わせは、トップページに記載の各SNSアカウントのメッセージ機能よりご連絡ください。
